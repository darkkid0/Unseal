# External Integrations

**Analysis Date:** 2026-07-13

## APIs & External Services

**macOS Security Services:**
- Extended attributes via `/usr/bin/xattr` - Reads and recursively removes only `com.apple.quarantine` from the user-selected `.app` in `Sources/UnsealCore/QuarantineService.swift`.
  - SDK/Client: Foundation `Process` through `SystemCommandRunner` in `Sources/UnsealCore/QuarantineService.swift`.
  - Auth: Current macOS user filesystem permissions; no credential or environment variable is used by `Sources/UnsealCore/QuarantineService.swift`.
  - Commands: `xattr -p com.apple.quarantine` and `xattr -dr com.apple.quarantine`, both assembled in `Sources/UnsealCore/QuarantineService.swift`.
- Gatekeeper via `/usr/sbin/spctl` - Reassesses the selected application after quarantine handling in `Sources/UnsealCore/QuarantineService.swift`.
  - SDK/Client: Foundation `Process` through `SystemCommandRunner` in `Sources/UnsealCore/QuarantineService.swift`.
  - Auth: Local Gatekeeper policy for the current macOS installation; `Sources/UnsealCore/QuarantineService.swift` supplies no credentials.
  - Commands: `spctl --assess --type execute <app-path>` in `Sources/UnsealCore/QuarantineService.swift`.

**macOS Login Items:**
- ServiceManagement `SMAppService.mainApp` - Registers, unregisters, checks approval state, and opens Login Items settings in `Sources/AppModule/LaunchAtLoginController.swift`.
  - SDK/Client: Apple `ServiceManagement` framework imported by `Sources/AppModule/LaunchAtLoginController.swift`.
  - Auth: User approval managed by macOS System Settings; no application credential is used in `Sources/AppModule/LaunchAtLoginController.swift`.
  - Fallback: A per-user `launchd` property list at `~/Library/LaunchAgents/io.github.darkkid0.Unseal.login-item.plist`, generated by `LaunchAgentLoginItem` in `Sources/AppModule/LaunchAtLoginController.swift` when `SMAppService` is unavailable.

**Apple Developer Distribution Services:**
- Apple code signing - Signs `.build/release/Unseal.app` in `package_app.sh` using either a local ad-hoc identity or the optional `SIGNING_IDENTITY` Developer ID setting.
  - SDK/Client: `codesign` and the local macOS Keychain, invoked by `package_app.sh`.
  - Auth: Signing certificate/private key selected by `SIGNING_IDENTITY`; credential material is not stored or read by `package_app.sh`.
- Apple Notary Service - Optionally submits and staples the packaged application for public distribution in `package_app.sh`.
  - Integration method: `xcrun notarytool submit --keychain-profile ... --wait` followed by `xcrun stapler staple` in `package_app.sh`.
  - Auth: macOS Keychain profile named by `NOTARYTOOL_PROFILE` in `package_app.sh`; actual credentials remain outside the repository.
  - Preconditions: `package_app.sh` requires `SIGNING_IDENTITY` whenever `NOTARYTOOL_PROFILE` is set.

**External Documentation:**
- Apple Support - The “查看帮助文档” action opens `https://support.apple.com/zh-cn/guide/mac-help/mh40616/mac` through SwiftUI's `openURL` environment in `Sources/AppModule/MenuContent.swift`.
  - Integration method: Opens the user's default browser; `Sources/AppModule/MenuContent.swift` does not make an in-process HTTP request.
  - Auth: None in `Sources/AppModule/MenuContent.swift`.

## Data Storage

**Databases:**
- None - `Package.swift` declares no database client or ORM, and application state in `Sources/AppModule/AppModel.swift` is in-memory apart from the preference and LaunchAgent entries described below.

**File Storage:**
- User-selected local `.app` bundle - `Sources/AppModule/DropZoneView.swift` accepts file URLs and `Sources/UnsealCore/QuarantineService.swift` validates that the path is an existing, non-symlink application directory before operating on its quarantine attribute.
  - SDK/Client: SwiftUI `dropDestination`, Foundation `URL`/`FileManager`, and the system `xattr` command in `Sources/AppModule/DropZoneView.swift` and `Sources/UnsealCore/QuarantineService.swift`.
  - Auth: Current user's local filesystem permissions; no elevated helper or Full Disk Access request exists in `Sources/UnsealCore/QuarantineService.swift` or `README.md`.
- Temporary command output - `Sources/UnsealCore/QuarantineService.swift` creates a unique temporary directory with mode `0700`, captures stdout/stderr in mode `0600` files, then removes the directory with `defer`.
  - SDK/Client: Foundation `FileManager` and `FileHandle` in `Sources/UnsealCore/QuarantineService.swift`.
  - Retention: Process-scoped only; cleanup occurs before `SystemCommandRunner.runSync` returns in `Sources/UnsealCore/QuarantineService.swift`.
- Login preference - `LaunchAtLoginEnabled` is stored in `UserDefaults.standard` by `Sources/AppModule/LaunchAtLoginController.swift`.
  - SDK/Client: Foundation `UserDefaults` in `Sources/AppModule/LaunchAtLoginController.swift`.
  - Scope: Current macOS user and app bundle domain established by the app metadata generated in `package_app.sh`.
- LaunchAgent fallback - `Sources/AppModule/LaunchAtLoginController.swift` atomically writes/removes a mode `0644` plist under the current user's `~/Library/LaunchAgents/` directory.
  - SDK/Client: Foundation `PropertyListSerialization`, `Data`, and `FileManager` in `Sources/AppModule/LaunchAtLoginController.swift`.
  - Contents: Launches the packaged app with `/usr/bin/open -g`, as defined in `Sources/AppModule/LaunchAtLoginController.swift`.

**Caching:**
- None - No cache framework or persistent result cache is declared in `Package.swift`; repair state is held only in `Sources/AppModule/AppModel.swift` and cleared by the user or application termination.
